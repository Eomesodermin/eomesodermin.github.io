# dilloncorvino.com

Source for my academic website, published with GitHub Pages at <https://dilloncorvino.com>.

A single static page (`index.html`) with no build step and no third-party scripts: fonts are
self-hosted in `fonts/`, and `sitemap.xml` and `robots.txt` are maintained by hand.

To preview locally, open `index.html` in a browser or run `python3 -m http.server`.
